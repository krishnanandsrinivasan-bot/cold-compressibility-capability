# Pad Development Tools V2

Multipage Streamlit engineering workspace for brake-pad development.

## Live module
- Cpk / Ppk Analysis
  - Excel / CSV upload
  - Copy/paste values
  - Dynamic manual table
  - Any practical sample size
  - Direct STDEV.S and I-MR sigma modes
  - Sequence/scatter plot
  - Normal distribution plot
  - Capability details and what-if analysis
  - Excel and CSV export

## Roadmap modules
- Compressibility Analysis
- Friction Analysis
- Wear Analysis
- NVH Analysis
- Brake Emission Analysis
- Supplier Comparison
- DVP / Report Generator

## Streamlit Cloud
Entrypoint: `app.py`

After files are committed to the same GitHub repository and branch used by Streamlit Cloud, the deployed app should reboot automatically from the new commit.
